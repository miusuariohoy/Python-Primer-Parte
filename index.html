1. Variables y tipos de datos

Una variable es una caja etiquetada donde el programa guarda un dato para usarlo despues. El signo = no significa "igual" como en matematica: significa guarda esto aca adentro.

Asignacion

nombre = "Ana"       # str   (texto)
edad = 15           # int   (entero)
altura = 1.62        # float (decimal)
aprobado = True     # bool  (verdadero/falso)

La caja puede cambiar de contenido en cualquier momento: edad = edad + 1 toma lo que habia, le suma 1 y vuelve a guardar.

Buena practica: en Python el tipo se deduce solo (no se declara como en otros lenguajes), pero conviene que una variable guarde siempre el mismo tipo de dato para no confundirse.

2. Toma de decisiones: if / elif / else

Un programa casi nunca hace siempre lo mismo: tiene que decidir. Pensalo como una bifurcacion en el camino: segun una condicion (verdadero o falso), el programa toma un camino u otro.

Sintaxis general

if condicion:
    # se ejecuta solo si la condicion es True
    instrucciones
elif otra_condicion:
    # se ejecuta si la primera fue False y esta es True
    instrucciones
else:
    # si nada anterior se cumplio
    instrucciones

Ejemplo: aprobo o reprobo

nota = 8

Con varias salidas posibles conviene encadenar elif:

if nota >= 8:

Ojo: Python evalua de arriba hacia abajo y entra solo al primer bloque que cumpla. Con nota 8 nunca llega al elif.

3. Ciclos: while, for, contador y acumulador

El while repite un bloque mientras una condicion siga siendo verdadera. Analogia: mientras llueva, quedate bajo el techo; cuando pare, sali.

while condicion:
    instrucciones          # se repiten mientras la condicion sea True
Idea clave: algo dentro del ciclo tiene que cambiar para que la condicion en algun momento sea False. Si nada cambia: ciclo infinito.

Forma 1: con contador (sabes cuantas vueltas)

i = 1
while i <= 5:
    print("Vuelta", i)
    i = i + 1            # sin esta linea: bucle infinito

Forma 2: con centinela (no sabes cuantas vueltas)

clave = ""
while clave != "1234":
    clave = input("Clave: ")
print("Acceso permitido")

for: cuando sabes cuantas vueltas

for i in range(1, 11):
    print(f"7 x {i} = {7*i}")   # la tabla del 7, completa

4. Ingreso y salida de datos

Todo programa interactivo hace lo mismo: ingresa un dato (input()), procesa, y muestra el resultado (print()). Ojo: input() siempre devuelve texto (str), aunque escriban numeros.

Ingreso: input() y conversiones

Salida: print() y f-strings

print(f"{n}x{i}={n*i}")         # asi arma las tablas de LasTablas.py

La f antes de las comillas permite poner variables entre llaves sin cortar el texto.

Patron completo

numero = int(input("Ingrese un numero: "))
doble = numero * 2
print(f"El doble es {doble}")

Este es exactamente el esquema del ejercicio doble.py visto en clase.

Error clasico: "2" + "3" da "23" (concatena texto) porque input trajo str. Sin int(), el programa corre pero calcula mal.
Buenas practicas con input:
  1. Mensaje claro que diga que dato se espera.
  2. Converti apenas lees: int(input(...)).
  3. Si puede fallar la conversion, protege con try / except (lo usamos en Adivina el numero).

5. Modularizacion: funciones con def

Una funcion es una caja con nombre que guarda instrucciones para reutilizarlas. Analogia: la receta de unas tortas fritas se escribe una vez y se usa cada vez que haga falta.

Partes de una funcion

def es_par(n):                # def + nombre + (parametros):
    if n % 2 == 0:        # cuerpo (con sangria)
        return True       # devuelve un valor a quien llamo
    else:
        return False

resultado = es_par(8)         # llamada: el valor queda en resultado
print(resultado)               # True
Definir no es ejecutar: el cuerpo corre recien cuando alguien llama a la funcion por su nombre.

    for i in range(1, 11):

tabla(7)                       # 7 es el argumento

Un parametro puede traer un valor precargado: si la llamada no lo envia, se usa ese.

Sin return: toda funcion devuelve None aunque tenga print. Print muestra; return entrega.

Locales y globales

  • Local: nace dentro de la funcion, muere al terminar.
  • Global: nace fuera; todas las funciones pueden leerla.
  • Para modificarla dentro de una funcion hay que declarar global.
intentos = 0                 # global

def sumar_intento():
    global intentos
    intentos = intentos + 1

En Adivina el numero hicimos esto mismo: global numero_secreto dentro de reiniciar().

Buena practica: usá global solo cuando sea necesario; lo ideal es pasar datos por parametros y recibir resultados con return.

6. Integracion: interfaz con Tkinter

Hasta aca el programa conversaba por consola. Con Tkinter (viene incluido en Python) armamos ventanas con etiquetas, campos y botones: el usuario interactua y el programa reacciona a eventos.

from tkinter import *

ventana = Tk()
ventana.title("Mi app")
ventana.geometry("400x300")

ventana.mainloop()      # deja la ventana viva, escuchando eventos

mainloop() es el motor: un ciclo oculto que espera clicks y teclas para disparar las funciones que indicaste.

Reglas de oro de Tkinter
  1. Nada de while ni input() dentro de una app de ventanas: bloquean el mainloop. El reemplazo del while es after(); el del input es el Entry.
  2. Los datos vivian en widgets: .get() para leer, .config() para cambiar, .delete(0, END) para vaciar.
  3. Boton lleva la funcion SIN parentesis; con datos, usa lambda.
  4. Si una funcion cambia una variable global, declara global.
  5. mainloop() siempre al final del archivo.
