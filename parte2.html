1. Listas: muchas cosas en una sola caja

Una lista guarda varios valores juntos y en orden, como un estante con casilleros numerados. Cada valor vive en una posicion que arranca a contar desde 0.

cursos = ["1A", "2A", "3A", "4A"]     # asi empieza planilla.py

print(cursos[0])          # 1A    (el primero)
print(cursos[2])          # 3A    (tercera posicion)
print(len(cursos))        # 4     (cantidad de elementos)
AccionCodigoQue hace
leer una posicioncursos[1]devuelve "2A"
cambiar un valorcursos[0] = "5A"pisa el primero
agregar al finalcursos.append("5B")crece la lista
insertar en mediocursos.insert(1, "6A")corre al resto
sacar un valorcursos.remove("3A")borra ese dato
ordenarcursos.sort()alfanumerico ascendente
recorrer con indicefor i in range(len(cursos)):i pasa por 0,1,2...
# Asi muestra el menu la planilla.py:
for i in range(len(cursos)):
    print(i, "-", cursos[i])

indice = int(input("Seleccione indice del curso: "))
print("Elegiste:", cursos[indice])
Error clasico: cursos[4] con 4 elementos da IndexError: las posiciones van de 0 a 3. El ultimo siempre es len(lista) - 1.
Buena practica: cuando muestres un menu numerado, usa ese mismo indice para leer la lista: cero traducciones y cero errores.

2. Tuplas: listas que no se cambian

La funcion exacta del proyecto

def mostrar_tabla(n):
    texto_tabla.delete("1.0", END)              # limpia lo anterior
    for i in range(1, 11):                       # vueltas: 1 a 10
        texto_tabla.insert(END, f"{n}*{i}={n*i}" + "\n")
  1. Borra el contenido viejo (si no, las tablas se mezclarian).
  2. Recorre 1..10 con for.

lambda: una funcion escrita en una linea

Paso 0 · como trabaja command. En un boton, command=saludar va SIN parentesis: no llamamos a la funcion ahora, le entregamos a Tkinter su direccion para que la llame mas tarde, recien cuando haya un click.

El problema: nuestros botones necesitan mandar el numero de tabla. Pero esto...

Button(frame2, text="7", command=mostrar_tabla(7))  # MAL: los parentesis ejecutan YA

...ejecuta la funcion al crear el boton, no al hacer click. Y sin parentesis (command=mostrar_tabla) falta el numero y da error en el click. Hace falta algo intermedio: una funcion que guarde adentro la llamada con su numero. Eso es lambda.

La sintaxis, comparada con def

def doble(x):                # funcion normal
    return x * 2

lambda x: x * 2              # EXACTAMENTE lo mismo, en una linea
PedazoSignificadoEquivalente en def
lambda"aca empieza una mini-funcion sin nombre"def nombre():
xlo que recibeel x de los parentesis
: x * 2lo unico que hace y devuelvereturn x * 2

Aplicado al boton de LasTablas

boton7 = Button(frame2, text="7", command=lambda: mostrar_tabla(7))
  1. Python crea la mini-funcion lambda: mostrar_tabla(7) y la deja guardada en command. Todavia NO se ejecuta nada.
  2. Haces click en el "7".
  3. Tkinter llama a esa mini-funcion (por eso funciona sin parentesis: Tkinter la invoca vacia).
  4. La mini-funcion corre su unica linea: mostrar_tabla(7). Recien AHORA se dibuja la tabla del 7.
FormaQue pasa
command=mostrar_tablafalta el numero n: error al hacer click
command=mostrar_tabla(7)se ejecuta YA al crear el boton (mal)
command=lambda: mostrar_tabla(7)espera el click Y manda el 7 (correcto)
Idea clave: lambda no ejecuta nada por si sola: fabrica la funcion y la deja lista, como un papelito que dice "cuando te llamen, mostra la tabla del 7". Tkinter guarda el papelito y lo lee en cada click.
Limite: lambda admite UNA sola expresion (una linea). Si necesitas varias instrucciones o un if complejo, usa def normal.

5. Canvas: dibujar, poner imagen y animar

El Canvas es un lienzo donde se colocan formas e imagenes, y cada objeto queda identificado por un id para poder moverlo despues. Es el escenario del sapo de LasTablas.py.

Crear lienzo e imagen

from PIL import Image, ImageTk

canvas = Canvas(frame5, width=1500, height=90)
canvas.pack()

img = Image.open("Sapo.jfif").resize((100,100))
img_Tk = ImageTk.PhotoImage(img)

sapo = canvas.create_image(100, 55, image=img_Tk)

create_image(x, y, image=...) devuelve el id del objeto (aca, sapo).

Moverlo en cada vuelta

# Mueve la imagen a la nueva posición
canvas.coords(sapo, x, ALTO // 2)

coords(id, x, y) teletransporta el objeto a esa posicion. Cambiar las coordenadas muchas veces seguidas = animacion.

La animacion completa: rebote izquierda-derecha

x, direccion = 100, 1            # direccion 1=derecha, -1=izquierda

def mover():
    global x, direccion
    x += 10 * direccion           # avanza 10 px por vuelta
    if x <= 100 or x > 1300 - 100:
        direccion *= -1           # toco un borde: invierte el sentido
    canvas.coords(sapo, x, ALTO // 2)
    base.after(30, mover)          # re-agenda: ~33 cuadros por segundo

mover()                            # primera llamada: arranca el loop
  • x += 10 * direccion: suma si direccion vale 1, resta si vale -1.
  • El if de bordes multiplica direccion por -1: rebota.
  • after(30, mover) re-agenda: mismo patron del cronometro de la Parte 1.

Simulacion del concepto

Cada cuadrito avanza 10px y rebota en los bordes: es el sapo, con otro disfraz.

Error clasico con imagenes: guardar img_Tk solo dentro de una funcion hace que la imagen desaparezca (el recolector la borra). Guardala en una variable global.

6. Musica de fondo con pygame

Pygame trae un reproductor de sonido (mixer) que puede sonar mientras la ventana sigue andando: perfecto para ponerle musica a LasTablas.

import pygame

pygame.mixer.init()                        # 1) enciende el sistema de audio
musica_tablas = "musica_tablas.mp3"          # archivo en la MISMA carpeta
pygame.mixer.music.load(musica_tablas)      # 2) carga el archivo
pygame.mixer.music.play(-1)                 # 3) reproduce en LOOP infinito
LineaQue hace
pygame.mixer.init()prepara el hardware de audio (una sola vez)
music.load(archivo)carga mp3/wav/ogg a memoria
music.play(-1)reproduce y repite para SIEMPRE (-1 = loop infinito)
music.play(3)suena 3 veces y para
music.stop()corta la reproduccion
Por que -1? El argumento es "cuantas veces repetir". Con 0 suena una vez, con 3 suena tres veces, con -1 el ciclo nunca termina: musica de fondo eterna.
Errores tipicos:
  • No llamar init() antes de load/play.
  • Ruta mal escrita: el archivo debe estar junto al .py (o pasar la ruta completa).
  • Formato no soportado: proba mp3 u ogg.
Idea integradora: podes combinar todo: boton "Musica ON/OFF" con command=lambda: pygame.mixer.music.stop() o con una funcion propia que alterne.

7. Formulario con base de datos (MySQL)

Meta final: una ventana donde cargar un alumno (nombre + curso), ENVIARLO a MySQL y despues MOSTRAR lo guardado. Orden del proyecto: primero armamos el formulario con Tkinter puro y lo probamos; recien despues le conectamos la base. Cuando llega la BD, todo el trabajo son tres verbos: CONECTAR (abrir la puerta), ENVIAR (INSERT + commit) y MOSTRAR (SELECT + fetchall).

Primero construimos y probamos la VENTANA completa: caja de nombre, desplegable de curso, pizarra para listar y dos botones. Si esto funciona solo, agregarle la base despues no rompe nada.

PASO 2 · CONECTAR: def conectar()

Una funcion chiquita que devuelve la conexion abierta. Las demas funciones la llaman cada vez que necesitan hablar con MySQL: abren la puerta, usan la base y la cierran.

import mysql.connector        # driver: pip install mysql-connector-python

def conectar():
    return mysql.connector.connect(
        host="localhost",
        user="root",
        password="",
        database="escuela"
    )
DatoValor tipicoSignificado
host"localhost"donde vive MySQL: esta misma PC
user"root"usuario de MySQL
password""clave del usuario (vacia en XAMPP recien instalado)
database"escuela"a cual base entrar (debe existir antes!)
Por que una funcion aparte? Los datos de acceso se escriben UNA sola vez. Si cambia la clave o el nombre de la base, editas conectar() y todo lo demas sigue igual.

PASO 3 · ENVIAR: def guardar()

def guardar():
    nombre = entrada_nombre.get()
    curso = combo_curso.get()

    if nombre == "" or curso == "":
        messagebox.showwarning("Falta dato", "Completa todos los campos")
        return

    try:
        cnx = conectar()
        cursor = cnx.cursor()
        sql = "INSERT INTO alumnos (nombre, curso) VALUES (%s, %s)"
        cursor.execute(sql, (nombre, curso))     # los valores viajan en una TUPLA
        cnx.commit()                             # confirma el cambio
        cnx.close()
        messagebox.showinfo("Guardado", "Alumno agregado con exito")
    except:
        messagebox.showerror("Error", "No se pudo conectar a la base")
  1. .get(): saca de la ventana lo que escribio/elegio el usuario.
  2. Validacion ANTES de tocar la base; return corta la funcion si falta un dato.
  3. try: si MySQL esta apagado no rompe el programa, salta al except y avisa con showerror.
  4. Pide la conexion a conectar() y crea el cursor: el "lapiz" que escribe sobre la base.
  5. Los %s son huecos; los valores viajan en una tupla aparte (nunca concatenar strings del usuario al SQL).
  6. commit() confirma el cambio; sin esa linea, el INSERT se pierde.
  7. close() cierra la puerta y showinfo celebra.

PASO 4 · MOSTRAR lo guardado (SELECT)

Mismo camino que ENVIAR, con distinto final: INSERT cambia datos y necesita commit(); SELECT solo consulta y responde con fetchall().

def mostrar():
    try:
        cnx = conectar()
        cursor = cnx.cursor()
        cursor.execute("SELECT nombre, curso FROM alumnos")
        filas = cursor.fetchall()            # devuelve LISTA DE TUPLAS
        # ej: filas = [("Ana", "1A"), ("Bruno", "2A")]

        texto_alumnos.delete("1.0", END)      # limpia antes de escribir
        for fila in filas:                    # cada fila es una tupla
            texto_alumnos.insert(END, f"{fila[0]} - {fila[1]}\n")

        if len(filas) == 0:
            messagebox.showinfo("Sin datos", "Todavia no hay alumnos")
        cnx.close()
    except:
        messagebox.showerror("Error", "No se pudo leer la base")
HerramientaQue hace
cursor.execute(sql)envia el SELECT (sin tupla de valores: no hay datos que proteger)
cursor.fetchall()trae TODAS las filas juntas, como lista de tuplas
fila[0] / fila[1]campo por posicion: el orden es el MISMO que se pidio en el SELECT

Su boton: Button(text="Mostrar", command=mostrar) — sin parentesis, como siempre.

PasoLineaSi falta...
1. abrir conexionconnect(host, user, password, database)todo lo demas falla
2. crear cursorcnx.cursor()no hay quien ejecute SQL
3. ejecutarcursor.execute(sql, tupla_valores)nada llega a la base
4. confirmarcnx.commit()el INSERT se pierde al cerrar
5. cerrarcnx.close()conexiones colgadas
Error clasico Nº1: olvidar commit(). El programa dice que guardo, pero al abrir phpMyAdmin no hay nada: la operacion quedo pendiente.
Buena practica: validar ANTES de tocar la base (campos vacios con showwarning) y proteger la conexion con try/except para responder con showerror si MySQL esta apagado.
